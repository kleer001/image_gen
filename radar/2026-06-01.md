# Model Radar — 2026-06-01
Window: first digest (no prior radar); 14-day window since ~2026-05-18; pre-window gaps flagged where significant. GPU ceiling: 24 GB (RTX 3090).

---

## Image base models

- **HiDream-O1-Image-Dev-2604** (9B, MIT) — Released May 14 2026. Novel unified Pixel-level Unified Transformer (UiT): no external VAE, no disjoint text encoders. FP8 community checkpoint (`drbaph/HiDream-O1-Image-Dev-2604-FP8`) fits ~10 GB VRAM at 28 steps; fp16 variant ~16–24 GB. Debuted #8 on Artificial Analysis Text-to-Image Arena at launch. ComfyUI 0.22.0 (May 20) adds native support. Fits 24 GB: **yes** (fp8, very comfortably). Source: [HiDream-ai/HiDream-O1-Image](https://huggingface.co/HiDream-ai/HiDream-O1-Image) · fp8 variant: [drbaph/HiDream-O1-Image-Dev-2604-FP8](https://huggingface.co/drbaph/HiDream-O1-Image-Dev-2604-FP8). Verdict: **try** — MIT license, small footprint, adds a fast non-Flux image path.

- **FLUX.2-Klein-9B** (9B, non-commercial — same terms as installed FLUX.1-dev) — Released ~Jan 2026 *(pre-window; no prior radar to catch it)*. 4-step distilled rectified flow transformer with 8B Qwen3 text embedder. Supports multi-reference conditioning (image editing + generation in one model). FP16 ~29 GB (over ceiling); FP8 official checkpoint (`black-forest-labs/FLUX.2-klein-9b-fp8`) ~15 GB — confirmed to run on RTX 3090 with headroom. Uses same ComfyUI FLUX nodes as FLUX.1-dev. Fits 24 GB: **yes (fp8)**. Source: [black-forest-labs/FLUX.2-klein-9B](https://huggingface.co/black-forest-labs/FLUX.2-klein-9B) · fp8: [black-forest-labs/FLUX.2-klein-9b-fp8](https://huggingface.co/black-forest-labs/FLUX.2-klein-9b-fp8). Verdict: **try** — 4-step inference, multi-reference editing, drops in like FLUX.1-dev.

- **FLUX.2-dev** (32B, non-commercial) — Released Nov 2025 *(pre-window)*. Unified generate + edit, native multi-reference conditioning. FP8 requires ~32 GB (over ceiling); GGUF Q4 (~19 GB + T5 offloaded to CPU) fits 24 GB. Significant quality upgrade over FLUX.1-dev but requires a GGUF loader (not standard ComfyUI FLUX nodes). Fits 24 GB: **quantized only (GGUF Q4)**. Source: [black-forest-labs/FLUX.2-dev](https://huggingface.co/black-forest-labs/FLUX.2-dev) · inference repo: [black-forest-labs/flux2](https://github.com/black-forest-labs/flux2). Verdict: **watch** — quality ceiling upgrade, but GGUF loader workflow needs validation before committing.

- **Illustrious XL v2.0** (SDXL, Apache 2.0 *unverified — check model card*) — *(pre-window gap)* Stack has v0.1 (early research, May 2024). v1.0 introduced 1536×1536 native resolution; v2.0 improves natural language robustness, color rendering, and fine-tuning stability. OnomaAI themselves state "there is no reason to use v0.1 over v2.0-STABLE." Fits 24 GB: **yes** (same size ~6.5 GB). Source: [OnomaAIResearch/Illustrious-XL-v1.0](https://huggingface.co/OnomaAIResearch/Illustrious-XL-v1.0) (v1.0 confirmed on HF; v2.0 via [CivitAI](https://civitai.com/models/1232765/illustrious-xl-10) — check for current stable). Verdict: **try** — drop-in swap; all existing SDXL workflows and LoRAs remain compatible.

## Video models

- **Wan 2.2 T2V-A14B** (14B active / 27B total MoE, Apache 2.0) — Released Jul 2025 *(pre-window gap)*. Stack has the I2V variant but **not T2V**. Same MoE architecture, same VRAM envelope (~18–20 GB), same ComfyUI-WAN-Wrapper dependency as installed I2V. Adds pure text-to-video capability without additional infrastructure cost. Fits 24 GB: **yes** (same as installed I2V). Source: [Wan-AI/Wan2.2-T2V-A14B](https://huggingface.co/Wan-AI/Wan2.2-T2V-A14B). Verdict: **try** — zero new dependencies; extends installed WAN to T2V.

- **SANA-WM** (2.6B, Apache 2.0) — Released May 16 2026 *(in window)*. NVIDIA open-source world model; 720p, minute-scale video with 6-DoF camera control. Despite small parameter count, inference variants require ~49–51 GB VRAM (bidirectional and chunk-causal modes); heavily quantized NVFP4 variant confirmed on RTX 5090 only. Fits 24 GB: **no**. Source: [Efficient-Large-Model/SANA-WM_bidirectional](https://huggingface.co/Efficient-Large-Model/SANA-WM_bidirectional) · paper: [arxiv 2605.15178](https://arxiv.org/abs/2605.15178). Verdict: **skip** — VRAM ceiling mismatch; revisit if sub-24 GB quantization path emerges.

- **WAN 2.7** — Alibaba previewed features (first-and-last-frame control, subject referencing, camera control) in April–May 2026, but **no HuggingFace model card with open weights found** as of this sweep. Multiple third-party articles describe it as available, but primary source (Wan-AI HF org) shows only Wan 2.2 models. Possibly API-only at this time. Source checked: [Wan-AI org on HF](https://huggingface.co/Wan-AI) — only 2.1/2.2 models present. Verdict: **watch** — check Wan-AI HF org weekly.

## ComfyUI nodes / tools

- **ComfyUI 0.22.0** (May 20 2026) — Adds native HiDream-O1-Image support with area conditioning, LTXV downscaled IC-LoRA, optional `attention_mask` input for video workflows, Seed2.0 node (ByteDance LLM integration), Save3D node with vertex color/texture support. Installed ComfyUI is at commit `45d5c83a` — will need update to use HiDream-O1 natively (otherwise use community node below). Source: [docs.comfy.org/changelog](https://docs.comfy.org/changelog) · releases: [github.com/Comfy-Org/ComfyUI/releases](https://github.com/Comfy-Org/ComfyUI/releases).

- **HiDream_O1-ComfyUI** (community node) — Custom nodes + LoRA training support for HiDream-O1, usable with pre-0.22.0 ComfyUI. Source: [Saganaki22/HiDream_O1-ComfyUI](https://github.com/Saganaki22/HiDream_O1-ComfyUI).

## Bottom line

The most actionable in-window find is **HiDream-O1-Image-Dev-2604** (MIT, 9B, fp8 ~10 GB) — it fills a gap for a compact, fast, non-Flux image model and ComfyUI 0.22.0 (also in-window, May 20) ships native support. Two significant pre-window gaps surfaced: **FLUX.2-Klein-9B** (fp8 ~15 GB, 4-step, multi-reference editing, same non-commercial terms as FLUX.1-dev) is a practical upgrade to the existing Flux pipeline; **Illustrious XL v2.0** replaces an 18-month-old v0.1 checkpoint that OnomaAI itself calls outdated. **Wan 2.2 T2V-A14B** also adds text-to-video capability with zero additional dependencies beyond what's already installed.
