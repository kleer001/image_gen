## Image base models
- **Ideogram 4.0** (9.3B, Ideogram Non-Commercial license) — open-weight T2I built around **structured JSON prompting**: bounding-box layout control + 16-color palette specs. Directly fills the repo's typography/graphic-design gap (today only covered by style LoRAs, no native layout control). ComfyUI **day-0 native** in v0.24.0 (2026-06-03) with `Ideogram4Scheduler` / `DualModelGuider` / `CFGOverride` nodes. nf4 + fp8 checkpoints on HF. Fits 24 GB: **yes** (9.3B; fp8/nf4 comfortable). Source: https://huggingface.co/ideogram-ai (release: https://blog.comfy.org/p/ideogram-4-day-0-support-in-comfyui). Verdict: **try** — non-commercial use only; best-in-class for text/layout.
- **FLUX.2 [klein]** (size-distilled 4B / 9B, **Apache-2.0**) — the open, locally-runnable member of the FLUX.2 family; successor lineage to the installed Flux.1-dev. A LoRA ecosystem is already forming around Klein 9B (see LoRAs). Fits 24 GB: **yes** (4B/9B; fp16 fine, fp8/GGUF trivial). Source: https://huggingface.co/black-forest-labs/FLUX.2-klein-4B (family: https://bfl.ai/blog/flux-2). Verdict: **try** — the natural open upgrade path from Flux.1-dev for this rig. *(Note: FLUX.2 base announced 2025-11-25 — outside the strict window but never catalogued here; flagging now.)*
- **FLUX.2 [dev]** (32B MMDiT, FLUX.2-dev **Non-Commercial** license) — best prompt-adherence of the family; multi-image gen+edit. Fits 24 GB: **quantized only** — fp16 ≈ 24 GB (no headroom), practical local path is **GGUF Q4_K_S ≈ 19 GB** (quality tradeoff). Drop-in for existing Flux tooling (path swap). ComfyUI day-0 support (2025-11-25). Source: https://huggingface.co/black-forest-labs/FLUX.2-dev. Verdict: **watch** — Klein is the better 24 GB fit; revisit dev if a GGUF build proves worth the squeeze.
